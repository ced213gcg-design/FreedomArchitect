# CCC Living Organism v10

This layer is the canonical machine-readable constitution for CCC v10 P0. It defines states, organs, hosts, roles, communication boundaries, release gates, and schema contracts.

## Rules

- Build is never completion; evidence earns state.
- Unknown or missing evidence never becomes PASS.
- Consequential actions require explicit human approval and step-up authentication.
- Legacy components are preserved and integrated through adapters/documentation.
- Imagination Station remains a separate organism with no CCC agent-mesh backchannel.
