# CCC v10.1 Communication Map

## Authority

`GitHub = CODE`  
`Ledger = FACT / EVIDENCE`  
`Orchestra = INTEGRATION / PLACEMENT / RELEASE`  
`Mission Control = PRESSURE / PRIORITY`  
`Exception Intelligence = SENSORY PRIORITY`  
`Codex = IMPLEMENTATION / REPAIR`  
`Slack = NOTIFICATION / REVIEW`  
`Gmail = EXTERNAL COMMUNICATION`  
`Living Dashboard = HUMAN DIGITAL TWIN`

Slack, Gmail and Codex never become institutional truth. Final state returns to GitHub + Ledger + Orchestra.

## Exception route

`EXTERNAL SIGNAL -> Exception Intelligence -> Ledger -> Mission Control -> Orchestra -> Dashboard`

High-priority sanitized summaries may also go to Slack. Consequential actions remain human-approved.

## Gmail route

Inbound opportunity email is only a signal:

`GMAIL -> exception-intelligence-agent -> VERIFY / FRESHNESS / SCORE -> Ledger -> Mission Control / Orchestra`

Approved outbound communication:

`AUTHORIZED DRAFT -> gmail-channel -> delivery evidence -> Ledger`

Failure:

`EMAIL_FAILED -> Ledger -> Exception Router -> Dashboard -> Slack fallback -> Human resolution`

## Security rules

No secrets, credentials, raw protected evidence, malware binaries, private customer/application details, raw financial credentials or arbitrary command payloads cross notification channels. Public dashboard/constellation payloads use allowlisted fields and evidence references rather than embedded sensitive documents.
