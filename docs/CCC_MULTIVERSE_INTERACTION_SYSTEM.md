## Interaction telemetry

Only semantic actions are accepted. Raw keystrokes, passwords, secrets, credentials, clipboard content, pointer coordinates and automatic screenshots are forbidden telemetry.

Navigation events remain local telemetry. Consequential requests are recorded as evidence-bearing requests and still do not execute the requested effect.
