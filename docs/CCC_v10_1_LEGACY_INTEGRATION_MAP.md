# CCC v10.1 Legacy Integration Map

## `06_Daily_Command_Dashboard`
Preserved as the daily human command/readout layer. v10.1 Living Dashboard is the evidence-bound digital twin; legacy Markdown state is not silently upgraded into verified telemetry.

## `09_Mission_State_Dashboard`
Purpose preserved. Useful mission fields may be adapted into v10.1 APIs but stale/manual values remain labeled unverified.

## `07_Unified_Launcher`
Preserved. The documented v10.1 dashboard launch path is `scripts/run_living_dashboard.sh` / `.ps1` or direct Python application start. Existing launcher behavior is not destroyed merely to create a fashionable new entry point.

## `13_Autonomous_Loop`
Controlled-autonomy principle preserved. It remains bounded preparation/tracking logic and is not converted into external auto-application, contract, grant or money-movement authority.

## `18_Controlled_Auto_Framework`
Historical separation-of-duty concepts are preserved. v10.1 registries/policies supersede it for explicit Agent Mesh registration, revocation, health and default-deny control.

## `05_Application_Engine`
Employment signals may feed Exception Intelligence only after source/freshness/evidence checks. Application history is not public constellation data.

## Historical gitlink
`01_Cybersecurity/GitHub` remains a preserved gitlink whose original external URL is not proven by a `.gitmodules` entry. v10.1 does not invent provenance to silence checkout warnings.

Law: `PRESERVE -> WRAP -> ADAPT -> SUPERSEDE -> DOCUMENT`.
