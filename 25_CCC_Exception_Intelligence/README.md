# CCC Exception Intelligence

Permanent sensory-priority organ for uncommon opportunities, threats, anomalies, constraints, breakthroughs and capability gaps.

Flow:

`SIGNAL -> VERIFY -> CROSS-EXAMINE -> SCORE -> LEDGER -> GAME THEORY -> MISSION CONTROL -> ORCHESTRA -> ACTION / HOLD`

The organ does not execute consequential actions. It verifies, scores, ages, records and routes evidence. Stale signals cannot remain VERIFIED. Missing evidence lowers fit/confidence rather than being guessed.
