### REQUIRED FOR EVERY CYCLE

Exactly five qualifying source records minimum.

The five sources MUST NOT:

- duplicate any source used in the immediately previous cycle;
- reuse the same exact source document already credited in the new run;
- originate from the same underlying report, dataset, proceeding, press release, study, filing, or research artifact merely through different URLs;
- be mirrors, reposts, syndicated copies, cached copies, derivative summaries, or repackaged copies of one another;
- inherit the material factual claim from the same unverified upstream source;
- count model output as evidence;
- count memory as a current source;
- count search-result snippets as source closure;
- count a citation merely because a URL exists;
- count five URLs as five independent families without upstream-lineage review.

### INDEPENDENT SOURCE FAMILY

A source family is independent only when its material evidentiary basis is independently attributable.

Different domains do NOT automatically equal different source families.

Same organization does NOT automatically mean same source family if the underlying evidence is truly independent, but reuse requires explicit AI-2 lineage review and must not violate the user's adjacent-cycle rule.

### ADJACENT-CYCLE LAW


No source family credited in Cycle N may be credited in Cycle N+1.
