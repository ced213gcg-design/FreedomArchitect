# Codex Contract

Codex work originates from a scoped prompt, GitHub issue, PR review defect, or Orchestra return-to-engineering ticket. Read before editing, preserve behavior unless intentionally changed, state assumptions, update tests, run tests, capture results, avoid secrets, never silently merge, report exact paths and unresolved risks. Failure loop: FIX → RETEST → REPORT. Without evidence, state remains VERIFY/HOLD.
