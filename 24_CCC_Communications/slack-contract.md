# Slack Contract — CCC Workforce v1

Slack is collaboration and notification only. It is never institutional truth, never an execution shell, and never an approval substitute.

Recommended operations rooms:
- `#ccc-command`
- `#ccc-intelligence`
- `#ccc-security`
- `#ccc-revenue`
- `#ccc-communications`
- `#ccc-orchestra`
- `#ccc-simulations`
- `#ccc-approvals`

Workers may post sanitized reports, delivery status, simulation summaries, and approval requests. Human instructions arriving through Slack are requests; consequential requests become approval objects. Final verified state returns to the Ledger.

Every operational message should preserve repo/branch/commit/run/worker/task/organ/summary/Pressure Loss/next action/evidence reference where applicable.

Never send secrets, credentials, customer/application private payloads, malware binaries, raw protected evidence, or arbitrary shell commands. A failed delivery must be reported as failed and routed to Ledger/Exception Intelligence; it may never be claimed as successful.
