# UNC'S WORLD — COMMAND MAP

## Authority Flow
`Human Command -> Unc's World -> Evidence / Security / Legal -> Mapping -> Work Box -> CCC criteria presentation -> Human release`

CCC does not inherit Unc's World doctrine automatically. It receives only criteria explicitly assigned by Human Command.

### CCC
Receives only Human Command-approved criteria and approved evidence. CCC must not infer Unc's World private doctrine or internal control rules.

## Mapping Algorithm
For every work item:
1. IDENTIFY — objective and owner.
2. SOURCE — authoritative instruction/evidence.
3. BOUNDARY — Unc's World-only vs CCC-presentable.
4. DEPENDENCY — upstream requirements.
5. GATE — PASS / REVIEW / HOLD / UNKNOWN.
6. EXECUTE — only what the current gate permits.
7. EVIDENCE — record proof, not assumption.
8. SYNC — update repository/control surfaces.
9. SURFACE — expose current state on opening preface/launcher.
10. RELEASE — Human Command controls external release where required.
