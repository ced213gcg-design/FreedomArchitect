# CCC Workforce v1

State: **INCUBATE** until implemented, tested, cost-controlled, and approved.

Five specialties operate as one CCC mind and one evidence lineage. This layer reuses the existing CCC Canon/Manifest, Ledger, Orchestra, Mission Control, Agent Mesh, Trust Fabric, state model, and Communications contracts. It does not create a parallel source of truth.

Canonical workers: `COMMAND`, `INTELLIGENCE`, `SECURITY`, `REVENUE`, `COMMS`.

Hard rules:
- default deny and least privilege;
- consequential actions require explicit human approval;
- unverified data cannot be promoted to fact;
- no worker may declare READY/THRIVE merely because it is running;
- every end-shift report carries exact next owner + next action;
- no universal worker credential;
- no unbounded autonomous loops;
- Slack/Gmail are communication channels, never institutional truth.

Conflict precedence: hard security/legal/human authority -> verified Ledger/live evidence -> ratified Canon/Manifest -> release/test evidence -> worker analysis -> unverified inference.

Implementation order follows the CCC Five Workers Operating Constitution v1. Draft PR is prohibited until evidence gates pass.
