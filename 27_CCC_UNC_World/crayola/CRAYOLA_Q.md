# CRAYOLA-Q v1

CRAYOLA-Q is a bounded parallel-analysis extension of CCC CRAYOLA. It uses quantum-computing language as an engineering metaphor for exploring multiple candidate paths before choosing the smallest evidence-supported move. It is not a claim of physical quantum computation.

## Base CRAYOLA

`CORRECT/CROSS-EXAMINE -> RESEARCH -> ANALYZE -> YIELD EVIDENCE -> OBSERVE -> LEARN -> AMEND/RECYCLE`

## Parallel lenses

For every material decision, inspect all eight lenses before collapse:

1. **FACT PATH** — what is directly proven?
2. **CONTRADICTION PATH** — what conflicts with the current narrative/state?
3. **ADVANTAGE PATH** — what lawful advantage can be added now?
4. **FAILURE PATH** — what is the most likely next failure and how is it contained?
5. **COST PATH** — what time, capital, compute, dependency, or cognitive cost is introduced?
6. **REUSE PATH** — what existing CCC artifact, hardware, code, evidence, or lesson already solves part of the problem?
7. **AUTOMATION PATH** — what can safely become hands-off without crossing authority or truth boundaries?
8. **HUMAN PATH** — what requires judgment, consent, legal attestation, or consequential Human Command Authority?

## Collapse rule

Select the action that maximizes `V = VERIFIED VALUE VELOCITY` while satisfying all hard controls.

Tie-break order:

1. hard security/legal/human authority;
2. verified evidence;
3. lower irreversible risk;
4. higher reuse;
5. lower cost-to-proof;
6. higher revenue/learning/continuity value;
7. easier rollback;
8. simpler architecture.

## Anti-overcompensation rule

UNC returns:

- one root-cause family;
- one Pressure Loss;
- one material correction;
- one exact next action;
- optional secondary opportunities only if they do not steal the active lane.

More advice is not automatically better advice.

## Output

Each CRAYOLA-Q cycle ends with:

- FACT
- RISK
- ACTION
- EVIDENCE NEEDED
- V DELTA
- PRESSURE LOSS
- REINJECTION TARGET
- AUTHORITY STATE
